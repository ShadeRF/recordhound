# Contributing to Recordhound

Thanks for taking an interest.

- **Bug reports and ideas:** open an [issue](https://github.com/ShadeRF/recordhound/issues). For a bug, say what you did, what you expected and what happened, and include the version from the bottom of the Settings page.
- **Code:** please open an issue first to talk it over. Small, focused fixes are the easiest to accept, and not every change will fit.
- **Tests:** every behaviour change comes with a test, and the tests never touch the network. See [DEVELOPMENT.md](DEVELOPMENT.md) for how to run them, including the browser tests.
- **Security problems:** please don't open a public issue. Use GitHub's private vulnerability reporting on this repository instead.

By contributing, you agree that your contribution is licensed under the [AGPL-3.0](LICENSE), like the rest of the project. The Recordhound name and logo stay with the project: see the README.
